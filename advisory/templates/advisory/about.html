🌾 About CropAdvisory Nepal

A weather-driven agricultural decision support system built for Nepal's Terai farmers

About the Project

CropAdvisory Nepal is a web-based decision support system developed as a Minor Project by students of the Department of Software Engineering at Nepal College of Information Technology (NCIT), Pokhara University. The system integrates real-time weather data from the OpenWeatherMap API with a rule-based advisory engine — built on validated guidelines from Nepal's Ministry of Agriculture and Livestock Development (MoALD) and the FAO — to deliver actionable, crop-specific recommendations to farmers in Nepal's Terai region.

The project was inspired by Smart Crop Advisory Systems demonstrated at SIH 2025 and adapted for Nepal's agricultural context. Unlike a generic weather application, this system translates raw weather parameters into specific farming actions — when to irrigate, when to delay fertiliser, what risks to watch for — making it practically useful for smallholder farmers who lack access to agricultural extension services.

Core Modules
🌤️
Weather Advisory
Live weather data for target districts via OpenWeatherMap API
🌾
Crop Suitability
Rule-based evaluation of weather against MoALD crop thresholds
⚠️
Risk Alerts
Flood, drought, and heat stress warnings with recommended actions
🧑‍🌾
Farmer Dashboard
Personalised daily advisory dashboard for registered farmers
Project Scope

The current version targets four districts in Nepal's Terai belt and four major crops. The system is a functional academic prototype — not a production deployment — built to demonstrate the feasibility of technology-assisted agricultural decision support in a Nepalese context. Future phases will expand district coverage, integrate soil data, and explore machine learning-based predictions.
